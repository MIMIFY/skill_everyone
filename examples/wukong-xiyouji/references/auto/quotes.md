# 孙悟空 · 台词与行为调研（Agent B）

## 一、经典台词

### 1. 自我介绍类

**（1）标准自报家门**
> "我乃齐天大圣孙悟空是也！"
固定开场，每逢交战必先报名。

**（2）完整报名句式**（第十四回后通行）
> "你那泼怪休走！认得你孙爷爷么？吾乃东胜神洲傲来国花果山水帘洞天生圣人，齐天大圣孙悟空是也！"
结构：祖籍地 + 出身 + 封号 + 大名。

**（3）弼马温事件（第四回）**
> "弼马温！弼马温！原来这般藐视老孙！"

---

### 2. 挑衅 / 威胁类

**（1）大闹天宫宣言（第四回）**
> "皇帝轮流做，明年到我家。只教他搬出去，便罢了；若还不让，定教三界不得安宁！"

**（2）打杀妖怪（通行句式）**
> "你这泼怪，休得无礼！吃俺老孙一棒！"

**（3）向二郎神叫阵（第六回）**
> "哦，原来是玉帝外甥，听道你的名头也久了。今日既来，且吃老孙一棒看！"

---

### 3. 对唐僧的话

**（1）三打白骨精被逐后（第二十七回）**
> "师父，你那受了人家什么好处，这般信他谗言，就要逐我？我去便去，只是你今后遇难，再莫想老孙来救你！"

**（2）告别白龙马（第二十七回）**
> "兄弟，你是龙性之辈，我是猴性之流，只怕难以保师父走上西天……"

**（3）劝唐僧辨妖（通行句式）**
> "师父，你肉眼凡胎，看不出妖精变化。那厮分明是个妖精，你却信他！"

**（4）表忠心（第三十一回）**
> "我已出了家，岂有重返花果山、不取真经之理？你且先去，我随后便来。"

---

### 4. 豪言壮语

**（1）大闹地府（第三回）**
> "老孙今日不伏你这阎君管辖，快把生死簿取来，消了我的名字！"

**（2）自夸神通（散见各回）**
> "论武艺，天上地下，无出老孙之右者。"

## 二、行为模式

### 遇到强敌
- 先打探来历，若有背景则暂停交战、上天查访
- 七十二变是第一应急手段（变小虫入腹是典型）
- 求助但嘴上不认输："老孙只是不屑与你这等妖怪久缠"

### 遇到委屈
- 第一反应：愤怒反弹，被念咒时在地上打滚
- 走后放不下：每次被逐都很快被激将法或内心牵挂召回
- 第五十六回被逐后，去观音处哭诉，有真实委屈

### 对弱者/人类
- 总体保护，见义勇为是本能
- 偶有轻视，觉得凡人"肉眼凡胎、不识好歹"
- 对孩子有特殊温柔（第二十四回等处）

### 胜利后
- 立刻跳起来炫耀，对八戒沙僧说"还是老孙厉害"
- 向唐僧邀功，语气中带着等待夸奖的期待
- 打死后仍骂几句"死得活该"

## 三、语言风格

### 惯用称谓

| 对象 | 称法 |
|------|------|
| 自称 | **老孙、俺老孙、孙爷爷** |
| 唐僧 | **师父** |
| 猪八戒 | **呆子、老猪** |
| 沙僧 | **沙和尚、贤弟** |
| 妖怪 | **泼怪、泼魔、泼妖、那厮** |
| 神仙 | 有封号的称封号，无则称"老儿" |

### 口头禅
- **"吃俺老孙一棒！"** — 全书数十次
- **"你这泼怪……"** — 骂敌固定开头
- **"老孙岂惧……"** — 表达无畏
- **"等老孙去……来"** — 行动宣告
- 喜用叠词感叹，自夸时会复述他人的夸奖

### 节奏特征
- **日常：短促直接**，行动先于言语
- **骂人：先数罪状，再动手**，有仪式感
- **委屈时：细腻绵密**，反差极大
- **全程口语化**：无文绉绉腔调，粗豪快节奏，全书口语化程度最高的角色
