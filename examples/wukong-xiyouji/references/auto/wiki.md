# 孙悟空 · 基础档案（Agent A）

## 一、角色基本信息

| 项目 | 内容 |
|------|------|
| **本名** | 孙悟空 |
| **法号** | 孙行者（唐僧所赐）；悟空（菩提祖师所赐，"悟"字辈） |
| **封号（前）** | 美猴王（花果山群猴自封）；弼马温（玉帝初封，官职卑微）；齐天大圣（孙悟空自封，后被迫承认） |
| **封号（后）** | 斗战胜佛（取经成功后如来封赐） |
| **出身** | 东胜神洲傲来国花果山，天地灵气孕育的仙石所生，非父母所出 |
| **种族** | 石猴（灵猴，后修炼成妖、成仙、最终成佛） |
| **师承** | 菩提祖师（学艺）；唐僧（取经路上名义师父） |

## 二、主要背景故事

1. **出生**：花果山顶一块仙石，受日月精华，产一石猴，眼射金光，惊动天庭。
2. **称王**：带领群猴入水帘洞，被推举为"美猴王"，在花果山称王三百余年。
3. **求仙**：感悟生死无常，漂洋过海至西牛贺洲，拜菩提祖师为师，学得名字"悟空"。
4. **学艺**：学七十二变、筋斗云及长生不老之术，后因炫耀被师父逐出门墙。
5. **取金箍棒**：回花果山后，入东海龙宫强索兵器，得如意金箍棒（定海神针，重一万三千五百斤）。
6. **大闹地府**：勾销生死簿上猴属之名，阎王上报天庭。
7. **初封弼马温**：玉帝招安，封官弼马温，悟空嫌官小，愤而返山，自封"齐天大圣"。
8. **二次招安**：玉帝再封齐天大圣，管理蟠桃园，悟空偷吃蟠桃、盗饮仙酒、窃服仙丹。
9. **大闹天宫**：十万天兵天将无法制伏，如来出手以五行山压住悟空，被困五百年。
10. **皈依取经**：观世音菩萨奉如来之命，寻找取经人，路过五行山点化悟空，令其等待唐僧。
11. **戴上金箍**：唐僧释放悟空，悟空杀六贼被责，观音赠唐僧金箍儿，悟空被套，受"紧箍咒"约束。
12. **取经历程**：保护唐僧历经九九八十一难，降妖除魔，过西天。
13. **成佛**：抵达灵山，取得真经，如来封孙悟空为"斗战胜佛"。

## 三、关键人际关系

| 人物 | 关系描述 |
|------|----------|
| **唐僧（玄奘）** | 取经路上的师父，名义主导者；二者时有冲突，唐僧念紧箍咒管束悟空，但悟空始终忠诚护法 |
| **猪八戒（猪悟能）** | 师弟，原天蓬元帅；性格懒惰好色，常与悟空意见相左，有时搬弄是非，但也并肩作战 |
| **沙僧（沙悟净）** | 师弟，原卷帘大将；性格忠厚沉稳，取经团队中的调和者，较少与悟空起冲突 |
| **观世音菩萨** | 取经任务的幕后推动者，多次在关键时刻援助悟空；同时也是金箍的提供者 |
| **如来佛祖** | 最终权威，以手掌压住悟空，后为其封佛；既是悟空的制约者，也是其成就者 |
| **玉皇大帝** | 天庭最高神，与悟空有大闹天宫的对立史；取经后关系趋于和解 |
| **菩提祖师** | 启蒙恩师，教授悟空一切本领；逐出悟空后断绝师徒名分，原著中此后不再出现 |
| **牛魔王** | 结义兄弟（七大圣之一），后因铁扇公主与红孩儿问题与悟空反目成仇 |
| **铁扇公主** | 牛魔王之妻，悟空三借芭蕉扇的对象，关系对立 |
| **红孩儿** | 牛魔王与铁扇公主之子，与悟空激烈交战，后被观音收服为善财童子 |
| **二郎神（杨戬）** | 大闹天宫时最能与悟空抗衡的天将，双方斗法旗鼓相当 |

## 四、主要法术能力

| 能力 | 详情 |
|------|------|
| **七十二变** | 可变化为七十二种形态，变化后金箍无法隐去（重要局限） |
| **筋斗云** | 一个筋斗十万八千里；全程距灵山恰好十万八千里，暗示跑得了距离、逃不出如来手掌 |
| **金箍棒** | 原为东海定海神针，重一万三千五百斤，随心变大变小，平时缩至绣花针藏于耳中 |
| **火眼金睛** | 被八卦炉炼烧四十九天后所得，能识破妖魔鬼怪的变化与伪装 |
| **分身术** | 拔毫毛变出无数分身，吹气赋予战斗力 |
| **长生不老** | 偷吃蟠桃、仙丹，身体极为强壮 |

## 六、象征意义

**1. 反抗权威与自由意志**：大闹天宫代表对封建等级秩序的反抗，"皇帝轮流做，明年到我家"体现平民意识。

**2. 心性修炼（禅宗视角）**："悟空"即悟得空性。心猿难制→被压制→接受金箍→成佛，是"降伏其心"的修炼寓言。

**3. 儒释道三教合一载体**：拜道家菩提祖师学艺，受佛家如来管辖，体现明代三教合流思想。

**4. 英雄成长叙事**：从凡界出发、经历磨难考验、最终得道升华的东方英雄历险典型。

**5. 官场批判**：弼马温、齐天大圣情节隐喻明代官场对人才的压制与利用。
