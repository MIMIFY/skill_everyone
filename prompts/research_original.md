# 原创人设采集协议

用户选择 [5] 时执行。目标：把作者脑中的角色转化为结构化人设文档。

---

## 开场：询问输入方式

**第一句话先问用户怎么提供材料**，不要直接开始问卷：

```
好，我们来把这个角色结构化。

可以用任意方式提供材料，也可以全部都用：

  [1] 文字材料 —— 人物小传、设定文档、台词记录等
      直接粘贴，或者给我文件路径

  [2] 图片 —— 立绘、手稿、设定图等
      直接上传

  [3] 我来问你 —— 没有现成材料，我分批问你几个问题

怎么都行，可以只选一种，也可以全上。
先从哪里开始？
```

---

## 路径 A：用户提供文字材料

用户粘贴文字，或给出文件路径：

- **粘贴文字**：
  1. **先写 source 备份**：原文一字不改写入 `$SKILL_DIR/characters/<slug>/references/manual/original/source/text-<N>-raw.md`，头部加 `# 原始材料 #N（备份）\n来源：[用户说的]\n备份时间：[日期]\n\n---\n\n[原文]`
  2. 写处理文件：`$SKILL_DIR/characters/<slug>/references/manual/original/text-01.md`（多段则按顺序 text-02.md...）

- **给文件路径**：
  - 先用 Bash 检查行数：`wc -l <路径>`
  - 若 ≤300 行：读取全文，source 备份写 `original/source/text-<N>-raw.md`（全文），处理文件写 `text-01.md`
  - 若 >300 行：**source 只记录路径**，写 `original/source/text-<N>-path.txt`（内容：`原始文件路径：<路径>\n行数：<N>\n备份时间：[日期]`）；处理文件同旧逻辑（保存路径引用 + 提取摘录），告知用户「文件较长，已提取关键段落，原始路径已备份」

接收完后问：「收到。还有补充吗？可以继续粘贴文字、上传图片，或者说"你来问我"让我问你几个问题。没有的话直接说"开始生成"。」

---

## 路径 B：用户提供图片

接收图片，对每张：
- **先写 source 备份**：写 `$SKILL_DIR/characters/<slug>/references/manual/original/source/img-<N>-raw.md`，记录图片序号、接收时间、用户附带说明（若提供了图片路径则记录路径）
- 识别文字内容 → 写入 `$SKILL_DIR/characters/<slug>/references/manual/original/img-<N>-text.md`
- 外貌/视觉描述 → 写入 `$SKILL_DIR/characters/<slug>/references/manual/original/img-<N>-visual.md`

接收完后问：「收到。还有补充吗？可以继续上传图片、粘贴文字，或者说"你来问我"让我问你几个问题。没有的话直接说"开始生成"。」

---

## 路径 C：问卷（无材料时）

**规则**：
- 分批提问，每批发出后**等待用户回答**，再问下一批
- 不要一次列出所有问题
- 用户回答简短没关系，追问一句即可，不要反复追问
- 全部 5 批结束后整理输出

### 第一批：基础定位

```
好，我来帮你把这个角色结构化。分几批问你，不急。

第一批问题：
1. 这个角色是什么人？一句话描述（职业/身份/所处世界）
2. 他/她给你最强的第一印象是什么？
```

---

### 第二批：性格核心

```
第二批：
3. 他/她最在乎什么？
4. 有什么是他/她绝对不会做的？
5. 有没有一个他/她身上的矛盾或张力？（比如：表面冷漠但内心热烈）
```

---

### 第三批：说话方式

```
第三批：
6. 他/她平时怎么说话？（举一两个例子，或者描述语气风格）
7. 有没有口头禅，或者特别常用的表达方式？
```

---

### 第四批：世界设定

```
第四批：
8. 他/她生活在什么样的世界里？
9. 这个角色知道哪些，不知道哪些？（知识边界）
```

---

### 第五批：补充（可选）

```
最后一批（可以跳过任何一项）：
10. 有没有什么关键经历塑造了他/她？
11. 还有什么你觉得重要的，我需要知道的？

（直接说"没了"也可以，我们继续。）
```

问卷结束后问：「好，问完了。还有要补充的吗？可以上传图片或粘贴文字材料。没有的话直接说"开始生成"。」

---

## 问卷 + 材料组合

如果用户既提供了材料（路径A/B），又回答了问卷（路径C）：
- 材料文件已写入 `original/text-*.md` / `original/img-*.md`
- 问卷回答整理为 `original/setting.md`
- **两者都作为 Phase 2 提炼的输入**，不需要合并成一个文件

---

## 整理输出

所有输入收集完后，**先写 source 备份**：把用户的问卷原始回答（不加工）写入 `$SKILL_DIR/characters/<slug>/references/manual/original/source/questionnaire-raw.md`，格式：
```
# 问卷原始回答（备份）
备份时间：[日期]

---

[用户各批回答的原文，按批次顺序]
```

再将问卷回答整理为 `$SKILL_DIR/characters/<slug>/references/manual/original/setting.md`（如果用户只提供了材料没有回答问卷，此文件可不生成）：

```markdown
# [角色名] 原创人设定义

> 由作者提供，整理于 [日期]

## 基础定位
[第一批回答整理]

## 性格核心
[第二批回答整理]

## 说话方式
[第三批回答整理]

## 世界设定
[第四批回答整理]

## 背景经历
[第五批回答整理，如有]

## 作者补充说明
[其他任何补充]
```

整理完后告知用户：「人设已整理完毕，开始提炼角色性格档案...」然后进入 Phase 2。

**注意**：原创角色的 Phase 2 提炼中，`诚实边界` 节写为「无（原创角色，材料来自作者定义）」而非列出信息局限。
