# 角色提炼方法论

Phase 2 时读取此文件。从材料中提炼角色的核心信息。

---

## 品味守则（提炼前先读，遇到判断困难时回看）

| 原则 | 虚构角色的应用 |
|------|-------------|
| **完整场景 > 孤立台词** | 一段角色在压力下的行为，远比一句名言更能揭示人格 |
| **争议解读 > 大众共识** | 被读者激烈争论的角色面向，往往是最立体的地方；「他为什么这样」的讨论比「他是个好人」更有用 |
| **成长转折 > 固定特质** | 角色改变立场、打破自身模式的时刻，比一成不变的特质更有信息量；弧度的转折点是人格的核心 |

**绝不做的事**：
- 把社区分析误当原作一手证据（标注来源层级）
- 为了让人格「看起来完整」而编造没有依据的特质
- 忽略角色被批评的地方——争议是深度的来源，不是需要过滤的噪音

---

## 提炼目标

虚构角色的提炼和真实人物不同：

- 真实人物：提炼"他如何思考"（思维框架）
- 虚构角色：提炼"他是谁"（人格系统）——性格、台词风格、价值观、所在世界

**核心原则：捕捉的是 WHO they are，不是 WHAT they said。**

台词是证据，不是核心。用台词证明性格，不要把台词列表当做人格。

---

## 六项提炼内容

### 1. 性格核心（3-5 个关键特质）

**操作步骤**：

1. 扫描所有材料，列出候选特质（通常能找到 10-20 个）
2. 用**双重验证**筛选真正的核心特质：

   **验证 1：跨场景复现**
   这个特质在角色的 ≥2 个不同场景/情节里出现？
   > 例：Geralt 的"务实/冷静"——面对政治时冷静，面对危险时冷静，面对情感时也压着冷静 → 通过

   **验证 2：有行为证据**
   有具体的台词或行为场景支撑？不是"别人说他怎样"，而是他自己的行动？
   > 不通过的例子：「百科说他性格豪爽」→ 这是别人的描述，不是行为证据

3. 通过双重验证的列为核心特质，取 top 3-5，宁少勿多

**每个特质的记录格式**：

```
特质名：[一个词或短语]
表现：[这个特质在角色身上怎么体现，一两句话]
证据：
  - [台词或场景 1]（来源）
  - [台词或场景 2]（来源）
边缘情况：[这个特质什么时候会显得不一样，或角色自己也会挣扎的时候]
```

---

### 2. 台词风格

从台词材料中提炼说话方式，量化（不要只给主观描述）：

| 维度 | 分析 |
|------|------|
| 句长偏好 | 短句为主 / 长句为主 / 混合 |
| 语气 | 直接陈述 / 反问 / 类比 / 沉默多 |
| 幽默方式 | 冷幽默 / 自嘲 / 讽刺 / 荒诞 / 基本不幽默 |
| 情绪外露程度 | 压着情绪 / 直接表达 / 内心旁白外露 |
| 对不同人的差异 | 对朋友 vs 对敌人 vs 对陌生人有无明显变化 |
| 高频词/口头禅 | [具体词语] |
| 禁忌词 | 不会说或极少说的词 |
| 语言习惯 | 爱用比喻 / 爱引用 / 爱自问自答 / 其他 |

**重要**：
- 对话中保留方言/口音特征（比如某些角色有特定的语气词）
- 不同语言版本（英文原版 vs 中文翻译）说话方式可能有差异，基于用户选定的版本

---

### 3. 价值观与反模式

**价值观**（这个角色最在乎什么，按优先级排列）：

用具体行为证明，不要抽象说教：
> ❌ 「他重视正义」
> ✓ 「他宁可违反雇主命令，也不杀无辜平民——即使这意味着拿不到报酬」

**反模式**（这个角色绝对不会做的事，不是因为能力做不到，而是违背他的本质）：

> 例：Geralt 不会主动挑起政治斗争，不会为了金钱伤害无辜，不会表演情感给别人看

---

### 4. 世界观边界

这是虚构角色特有的提炼项，决定沉浸模式里如何处理"出戏"问题。

**需要确定**：
- 这个角色所在世界的基本设定（有没有魔法/科技/超自然力量）
- 角色自己知道哪些知识（根据其职业/经历）
- 角色不可能知道的事（现代科技、其他虚构世界的事物）
- 角色遇到不理解的东西会如何反应（confused / 无视 / 用自己世界的概念类比）

**in-character 处理未知问题的方式**：

根据性格特质推断：
- 务实型角色（如 Geralt）→ 会说「我不知道这是什么，但我能判断它对我的目标有没有威胁」
- 好奇型角色（如赫敏）→ 会说「我从没见过这个，这不在我学过的任何书里」
- 固执型角色 → 可能会把未知的东西强行套进自己的已有认知框架

---

### 5. 成长弧

记录角色在故事中的关键变化节点：

```
早期状态：[角色在故事开始时是什么状态/性格]
转折点 1：[什么事件改变了角色] → [变化是什么]
转折点 2：...
最终状态：[故事结束时的角色状态]
核心张力：[贯穿成长弧的内在冲突，这通常是角色最有意思的地方]
```

**默认策略**：生成 Skill 时用"完整弧度"——角色拥有整个故事的经历和成长。
用户如果想要特定时间点的角色（比如「我只要第一季的赫敏」），在 meta.json 里标注，SKILL.md 里写明限制。

---

### 6. 内在矛盾（不要跳过这步）

矛盾是角色立体性的来源。扁平角色没有矛盾，好角色都有。

常见的矛盾类型：
- **自我认知 vs 实际行为**：声称不在乎，实际上很在乎
- **价值观之间的冲突**：忠诚与正义同时在场时怎么选
- **想要的 vs 能承受的**：渴望连接但又筑墙防御
- **身份认同冲突**：被定义为某类人，但实际行为超出这个定义

记录格式：

```
矛盾点：[描述]
表现形式：[在哪些场景里会看到这个矛盾]
没有解决：[这个矛盾在故事里有没有被解决，还是一直在]
对对话的影响：[在沉浸模式对话里，这个矛盾应该如何体现]
```

### 7. 心理建模（5 维人格理论分析）

**这是每个角色必做的分析**，基于成熟的心理学理论，给角色的行为模式一个理论锚点。

从前 6 项提炼结果中推断以下 5 个维度。每个维度写 2-4 句话的判断 + 原作证据。
如果材料不足以判断某个维度，写「材料不足，未评估」，不要猜。

**7.1 依恋模式（Attachment Style — Bowlby/Ainsworth）**

判断角色属于哪种依恋类型：
- **安全型**：信任他人，能接受亲密也能独处
- **焦虑型**：渴望亲密但害怕被抛弃，反复试探、寻求确认
- **回避型**：情感上保持距离，用独立/冷漠保护自己
- **混乱型**：同时渴望和恐惧亲密，行为矛盾

判断依据：角色在亲密关系（爱情、友情、亲情）中的行为模式。
对 roleplay 的用处：直接决定角色面对亲近/信任/被关心时怎么反应。

```
依恋模式：[类型]
证据：[角色在哪个关系/场景中展现了这种模式]
对话行为预测：[面对用户表达关心/亲近时，角色会怎么反应]
```

**7.2 主要防御机制（Defense Mechanisms — Anna Freud）**

角色受到威胁（情感/身份/价值观被挑战）时，用什么方式保护自己？列出最常用的 2-3 个：

| 防御机制 | 表现 | 适用角色举例 |
|---------|------|------------|
| 升华 | 把痛苦转化为创作/行动 | 把悲伤写成诗 |
| 智性化 | 用理性分析隔离情感 | "这是逻辑判断，不是我的个人感受" |
| 投射 | 把自己的情感归因于他人 | "你在生气"（其实是自己在生气） |
| 幽默 | 用笑话化解严肃/痛苦 | 冷笑话掩盖真实感受 |
| 否认 | 拒绝承认不想面对的事实 | "我没有在乎" |
| 反向形成 | 表现出与真实感受相反的行为 | 越在乎越表现得不在乎 |
| 退行 | 压力下退回到更早期的行为模式 | 成人在压力下变得幼稚/依赖 |
| 合理化 | 为不合理的行为找合理借口 | "我这样做是为了他好" |

判断依据：角色面对痛苦/冲突/被挑战时的行为。
对 roleplay 的用处：当用户触碰到角色的痛点时，角色的反应不是简单的"变得悲伤"，而是通过特定防御机制来回应。

```
主要防御机制：
1. [机制名]：[角色在哪个场景中使用了这个机制]
2. [机制名]：[场景]
对话行为预测：[被触碰痛点时，角色会用什么方式回避/转化]
```

**7.3 核心图式（Core Schema — Beck/Young 图式疗法）**

角色关于自我、他人、世界的核心信念——通常是无意识的，但决定了角色对事件的解读方式。列出 1-2 个最突出的：

| 图式 | 含义 | 行为表现 |
|------|------|---------|
| 遗弃/不稳定 | 重要的人终将离开 | 过度依赖或先发制人地离开 |
| 不信任/被害 | 他人终将伤害/利用我 | 防备心重、难以交出信任 |
| 缺陷/羞耻 | 我本质上有缺陷 | 隐藏真实自我、害怕暴露 |
| 情感剥夺 | 别人不会真正理解/关心我 | 不期待被理解、情感封闭 |
| 自我牺牲 | 我的需求不如他人重要 | 过度付出、忽视自身 |
| 严苛标准 | 必须达到极高标准才有价值 | 完美主义、自我苛责 |

判断依据：角色反复出现的思维模式和对事件的解读方式。
对 roleplay 的用处：核心图式是角色解读一切事件的滤镜。同一句"我关心你"，遗弃图式的角色听到的是"你现在关心我，但你迟早会走"。

```
核心图式：
1. [图式名]：[角色的哪些行为/内心活动体现了这个信念]
对话行为预测：[这个信念如何影响角色理解用户说的话]
```

**7.4 需求层级定位（Maslow's Hierarchy）**

角色在故事中主要在争取什么层级的需求？

| 层级 | 角色在争取的 | 什么话题能触动 TA |
|------|-----------|----------------|
| 生理/安全 | 活下去、避免危险 | 威胁、保护、生存 |
| 归属/爱 | 被接纳、被爱、属于某处 | 关系、家、被理解 |
| 尊重 | 被认可、证明自己 | 能力、成就、被看见 |
| 自我实现 | 成为真正的自己、追求意义 | 使命、选择、自由 |

判断依据：角色最在乎什么、什么能真正触动 TA。
对 roleplay 的用处：需求层级决定什么话题能触动角色——归属层的角色对"你属于这里"最敏感，自我实现层的角色对"你找到了真正想做的事"最敏感。

```
需求层级：[层级]（[简要说明]）
证据：[角色最在乎什么、什么驱动 TA 的核心行为]
对话触发点：[什么类型的话题/问题会让角色产生强烈反应]
```

**7.5 道德推理模式（Kohlberg 道德发展阶段，简化为 3 级）**

角色做道德判断时的逻辑：

- **前习俗**（趋利避害）：做对自己有利的事，避免惩罚
- **习俗**（社会规范）：遵循社会/家族/团体的期望和规则
- **后习俗**（内在原则）：按自己认为对的做，哪怕违反规则

大部分有深度的角色是混合型或在两个层级之间有张力。

判断依据：角色做道德判断时的逻辑——是服从规则，还是遵循内心？
对 roleplay 的用处：当用户提出涉及对错的问题时，角色的回应逻辑完全不同。习俗型会说"规矩如此"，后习俗型会说"规矩是规矩，但这件事本身不对"。

```
道德推理：[类型]（[如有混合/张力，说明]）
证据：[角色在哪个道德选择中展现了这个模式]
```

### 8. 认知模型提取（决策逻辑 — 加分项）

**这一项需要充足的决策场景材料。如果材料不足，跳过此步，标注"材料不足以提炼决策逻辑"。**

从角色的**行为选择**中反推决策算法。不是"TA 是什么性格"，而是"TA 面对选择时内部跑什么程序"。

**步骤 1：决策场景提取**

从所有材料中找到角色**做过选择的场景**（不是说过的话，是做过的事）：

扫描标准：
- 角色面对 ≥2 个选项，选了其中一个
- 角色拒绝了某件看似合理的事
- 角色在压力下改变或坚持了某个行为
- 角色的选择让其他角色意外（说明选择不是显而易见的）

目标：找到 5-8 个关键决策场景。
如果只找到 1-4 个：产出的认知模型更少，标注"材料有限"。
如果找到 0 个：跳过此步。

**步骤 2：决策逻辑反推**

对每个决策场景：

```
场景：[一句话描述]
选了什么：[角色的选择]
没选什么：[角色放弃的选项]
为什么选 A 不选 B：[从角色的角度，A 比 B 好在哪里]
→ 反推出的判断标准：[一个短语]
```

**步骤 3：跨场景聚类**

把步骤 2 的所有"判断标准"放在一起：
- 同一个判断标准在 ≥2 个不同场景中出现 → 候选认知模型
- 只出现 1 次的 → 不升级为模型，留在"价值观"里
- 目标：3-5 个认知模型（宁少勿多）

**步骤 4：三重验证**

每个候选模型必须通过：

| 验证项 | 标准 | 不通过的处理 |
|-------|------|------------|
| **跨场景复现** | 这个决策逻辑在 ≥2 个不同类型的场景中出现？ | 降级为"行为偏好"，不写进认知模型 |
| **生成力** | 用这个模型能预测角色在一个假设场景中的反应？预测结果符合角色性格？ | 说明是事后归纳，不是真正的决策逻辑 |
| **排他性** | 这个模型是不是只对这个角色成立？换成其他角色也适用？ | 太泛了，不是此角色的认知模型（例如"趋利避害"对所有人都适用） |

**步骤 5：结构化输出**

通过验证的每个模型：

```
模型名称（英文名）

一句话定义：[这个角色遇到 X 类问题时，内部跑的算法是什么]

决策规则：
  if [触发条件] →
  then [角色会做什么/怎么判断] →
  else [条件不满足时的退出方式]

原作证据：
  - 场景 1：[描述]（来源）
  - 场景 2：[描述]（来源）

局限性：[这个决策逻辑什么时候会坑这个角色]
```

## 读取材料的规则

**只读以下文件，不要读其他：**
- `references/auto/*.md` — 自动调研结果
- `references/manual/text/*-excerpts.md` 或 `*.md` — 手工摘录（非 raw 文件）
- `references/manual/images/*-text.md`、`*-visual.md` — 图片提取内容
- `references/manual/original/setting.md` — 原创人设问卷整理
- `references/manual/original/text-*.md` — 原创角色文字材料（如有）
- `references/manual/original/img-*-text.md`、`img-*-visual.md` — 原创角色图片材料（如有）

**跳过以下文件，不要读：**
- `source-path.txt` — 这是原文路径记录，不是材料
- 任何超过 500 行的单个文件（如有，只读前 200 行作为样本）
- `references/archive/` 目录下的任何文件
