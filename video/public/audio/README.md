# 音频文件说明

将以下音频文件放置在此目录以启用卡点配音：

## 文件列表

| 文件名 | 用途 | 建议时长 |
|:---|:---|:---|
| `bgm.mp3` | 背景音乐（全程） | 56秒 |
| `narration_intro.mp3` | 旁白：开场 | ~5秒 |
| `narration_outro.mp3` | 旁白：结尾 | ~4秒 |
| `sfx_typing.mp3` | 键盘打字音效 | ~8秒 |
| `sfx_scan.mp3` | 扫描/研究音效 | ~9秒 |
| `sfx_success.mp3` | 成功提示音（短） | ~1秒 |

## 旁白脚本

### 开场旁白（第 0-4 秒）
> "有些人，用一生写了一封信。收信人，只有一个。"

### 结尾旁白（第 52-56 秒）
> "你也可以，召唤任何人。"

## 音乐建议

- **风格**：轻缓电子/钢琴，参考《火影忍者》原声
- **关键节拍**：
  - 第 4s（120帧）：进入节拍，终端出现
  - 第 22s（660帧）：心理建模，音乐稍加强度
  - 第 31s（930帧）：角色生成，短促成功音
  - 第 36s（1080帧）：对话开始，音乐转为安静
  - 第 50s（1500帧）：最后一行「只是疼，不影响答案」，情感高峰

## 推荐 TTS 服务（用于旁白）

- Azure Neural TTS（中文普通话，男声沉稳）
- ElevenLabs
- 微软 Edge TTS（免费）

## 在代码中启用音频

在 `SkillEveryone.tsx` 中取消注释以下行：

```tsx
import { Audio, staticFile } from 'remotion';

// 在 AbsoluteFill 内添加：
<Audio src={staticFile("audio/bgm.mp3")} volume={0.4} />
```
